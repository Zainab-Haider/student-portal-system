# Student Task Management System

## Project Purpose
The Student Task Management System is a web-based application that helps students organize and manage their academic work in one place. Students can create, edit, and delete tasks, set deadlines, update task statuses, and track their academic progress.

## Project Objectives
- Provide a centralized platform for managing academic tasks.
- Help students organize assignments, projects, and quizzes.
- Track task completion using To Do, In Progress, and Done statuses.
- Help students monitor upcoming deadlines.
